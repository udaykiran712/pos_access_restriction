Why Do Retailers Need This Module?

Standard Odoo POS creates checkout bottlenecks and allows accidental negative inventory sales.

❌ Standard Odoo POS Limitations
  • • Cashiers must open the (i) info popup for every product just to check available stock.
  • • Negative inventory is permitted by default, causing stock discrepancies.
  • • Unit price is not visible on the product card tile.
  • • Cashiers can add more units to the cart than physically exist on shelves.
✅ With This Extension
  • • Instant Price Badge: View live selling prices right on the product tile.
  • • Location Stock Status: Immediate color-coded stock count (Green / Orange / Red).
  • • Strict Sale Blocker: Halts checkout when stock is 0 or when cart demand exceeds available stock.
  • • Location-Scoped: Strictly computes stock for the POS terminal source location.

Under The Hood

Performance Architecture

⚡ O(1) Batched Quant Query

Stock is resolved using a single SQL _read_group on stock.quant across all loaded products. Eliminates per-product loops and maintains flat load times.

🛡️ Internal Location Scoping

Stock queries are scoped to location_id.usage = 'internal'. Virtual inventory adjustment quants never distort physical shelf counts.

🧩 Pure OWL 2 Component Extension

Built with native OWL 2 patch() and XML extension inheritance. No core files overwritten; clean upgrade path.

🔄 Multi-Channel Blocker

Intercepts card clicks, barcode scanner inputs, and search additions while safely allowing return and refund orders.
