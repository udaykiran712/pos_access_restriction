POS User Access Restriction (Odoo 18)

Secure your retail operations by binding standard POS users strictly to their assigned shops.

The Problem

By default, granting a user 'POS User' access in Odoo allows them to view every Point of Sale configuration, access any active register session, and browse company-wide orders and payment history. For business owners managing multiple locations, branches, or franchises, this is a major security flaw.

Key Features

Granular Restrictions

Explicitly select one or multiple POS shops a user is authorized to interact with directly from their profile.

Multi-Company Alignment

The configuration field automatically honors allowed company parameters, completely preventing cross-company shop assignments.

Complete Data Isolation

Secures the dashboard, active sessions, backend order listings, and financial payment lines via underlying secure record rules.

Safe Reporting

Automatically filters out analytical rows in complex SQL view pivots, ensuring metrics match only assigned configurations.
